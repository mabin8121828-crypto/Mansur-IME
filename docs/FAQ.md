# 常见问题

[首页](../README.md) · [快速开始](QUICK_START.md) · [使用手册](USER_GUIDE.md)

## 下载 ZIP 后怎么安装？

GitHub 的 Download ZIP 是源码，不是安装包。请按[构建说明](BUILDING.md)运行。
当前尚无独立电脑验收后的二进制发行。已有试用包则需要完整解压，不能在压缩
预览产生的临时目录运行脚本。

## 设置在哪里打开？

已有安装可双击桌面 **Mansur 输入法设置**，点击悬浮状态栏齿轮，
或右键托盘图标选 **设置…**。修改后保存；模型页按钮为 **保存并应用**。

## 按空格选了中文，为什么没有英文？

候选空格只用于选词。选好词后，再快速按三次空格，才会提交并学习。
三次应分别按下，长按不算。如果已有提交结果仍没有英文，再检查后台和模型配置。

## Enter 会翻译或发送消息吗？

Enter 不触发学习。仍有待选拼音时，先将其按原文加入草稿；没有待选拼音时
提交当前整句。消息发送使用应用本身的操作，输入法不会自动发送。

## 怎么输入 Hello 或 mansur？

轻按 Shift 切到英文模式后输入，英文及大小写保持原文。
快速三空格可显示并朗读英文原文，不必切到另一个输入法。

## 能听到，但没有看到英文？

浮窗在播放完成后约三秒收起；鼠标悬停或选择时保留。
可从托盘 **重播本句** 再次查看。如果从未显示过，属于需要报告的问题，
请提供输入法版本、Windows 版本、应用、显示缩放及固定复现步骤。
仅听到声音不能证明窗口实际可见。

## 有英文但没有声音？

翻译和朗读是两项独立配置。检查系统音量、对应朗读服务的模型和音色，以及
本地模式的 Python 与 Kokoro 文件。需要时查看[模型配置](LOCAL_MODELS.md)。
Windows 英语声音回退默认关闭，只有你明确启用并安装了系统英语声音才会使用。

## 保存后 API 密钥框为什么是空的？

已经保存的密钥不会自动回填到可见文本框。核对页面的已保存状态；
留空保存会保留原有凭证，填写新值才替换。不要为了确认而公开密钥截图。

## 检查配置成功，为什么实际生成还失败？

部分检查只验证字段或文件。真实服务还受到模型权限、账户额度、接口地址、
网络和输出格式的影响。配置检查与实际生成是不同验证范围。

## 提示 API 密钥未通过验证，是否一定是密钥错了？

401 通常涉及认证，403 也可能涉及账户或模型权限。先确认对应服务、地址和
模型，再查看厂家控制台。不要在问题报告里附上凭证；提供不含正文的错误码即可。

## 后台暂不可用，怎么办？

基本中英文输入应继续可用。已有完整试用安装可运行 **启动英文伴读.cmd**；
托盘可选 **重启学习服务**。登录后自动启动在 **英语朗读** 页启用并保存。
如果配置文件损坏，仍应能够打开设置修复。

## 更新后每个软件都要反复重开吗？

原生输入组件由各应用加载。涉及 DLL 更新时，按版本说明执行一次统一的
Windows 重启。仅文档更新不改变安装，也不要求重启。不能靠反复重开个别应用
代替对整个安装、更新和卸载流程的验证。

## 选中英文为什么没有自动查词？可以选网页文字吗？

选择本身不发起模型请求。选中后主动点击查询或按 Ctrl + D；朗读为 Ctrl + R。
当前只支持 Mansur 已有英文浮窗内的内容，尚未实现网页划词。
释义是模型参考，专有名词解释和音标可能不完整。

## 常用词为什么不总排第一？

个人词频会影响排序，但不保证超过所有普通词。自动拼接控制长度，长词要求
完整匹配，避免输入短拼音时不断冒出过去的一整句话。可导入个人词库或关闭自动记词。

## 复制英文会直接写入聊天框吗？

不会。复制图标复制整句；拖选后 Ctrl + C 复制所选内容，再由你自行粘贴。
当前已撤销自动写回，不替换中文、不追加译文、不发送消息。

## 有费用吗？能商业使用吗？会上传输入历史吗？

项目自有代码采用 MIT，允许商业使用和修改；再分发需保留版权及许可。
API 按你选择的厂商收费，本地运行需要模型、磁盘和算力。
模型、运行库和第三方图标分别遵守各自许可。

API 只处理你明确确认的本句或显式选择学习的内容，不读取宿主全文或剪贴板历史。
个人短词记忆留在本机；完整说明见[隐私说明](PRIVACY.md)和
[第三方说明](../THIRD_PARTY_NOTICES.md)。

## 其他电脑要验证什么？遇到问题怎么反馈？

独立电脑需要验证首次安装、双架构输入、中文和英文、翻译与朗读、复制、
学习服务退出后的基本输入，以及更新、卸载和数据保留。
自动检查不能证明全部操作系统、应用和服务厂商可用。

在[问题入口](https://github.com/mabin8121828-crypto/Mansur-IME/issues/new/choose)
填写版本、应用、固定步骤、预期与实际结果。截图遮住私人聊天、密钥、账户信息；
不要上传个人配置、完整日志、词库或凭证。参考[已知限制](KNOWN_ISSUES.md)。
