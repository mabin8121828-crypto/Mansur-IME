# 数据与凭证

Mansur的输入核心与学习后台分开。普通中文输入不依赖模型服务。
快速三空格显式确认学习时，中文/混合句发送给用户选定的翻译服务，得到的
英文再交给选定的朗读服务。纯英文跳过翻译并按原文朗读。

英文浮窗的选词学习仅处理本产品已经显示的英文。用户明确点击查词/朗读后，
所选内容及对应本句语境可交给选定服务。普通选中、复制或打开设置不触发生成。
未实现网页或其他应用全文读取。云服务可能按自己的条款处理数据和收取费用，
使用者应自行确认其服务条款。

API密钥在当前Windows用户账户下通过DPAPI保存，不放进源码、安装包或明文
模型配置。不同服务使用独立密钥；没有对应凭证不自动改用其他厂家。
个人词库只在本机保存短词、拼音和次数，可在设置关闭；不保存整句学习历史。
运行诊断使用固定状态码、时间、计数等元数据，不应记录输入正文或密钥。

复制操作由用户显式发起，只写入所选英文或完整英文，不读取原剪贴板。
Mansur不自动向目标编辑器写回译文、不替用户发送消息。

公开源码导出采用允许清单，排除用户配置、密钥、模型、运行日志、本机交付
历史和截图。导出程序还检查常见密钥和私钥模式；这属于有范围的检查，不能
保证识别任意形式的秘密。提交前仍应人工查看最终文件清单。
