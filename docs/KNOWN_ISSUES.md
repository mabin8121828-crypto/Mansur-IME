## 当前使用边界

- 查词只处理现有英文浮窗的选中内容。模型释义可能不够精确，专有名词和音标可能缺失。
- 没有网页划词、麦克风评分或生词本。
- 英文自动写回已经撤销；复制后自行粘贴。
- GitHub Download ZIP 是源码；模型权重、Python 和相关运行库需要另行准备。
- 本地朗读基线 `kokoro-onnx 0.6.1` 要求 Python `>=3.10,<3.14`，推荐 Python 3.12。
- API 请求受服务权限、额度、网络及接口差异影响；本地配置有效不等于认证或生成成功。
- Windows 声音备用仅在用户明确启用时使用，并要求系统有可用英语声音。
- 不承诺所有电脑达到固定秒数或所有模型得到相同译文。

## 其他电脑的验收清单

使用固定演示句，分别记录版本、Windows 版本、应用和结果：

1. 干净安装成功，系统可选择输入法；不依赖旧工程或开发者电脑路径。
2. 中文候选、翻页、删改、取消、Enter、快速三空格和个人短词记忆。
3. Shift 英文、大小写、人名、中英混合以及窗口切换时草稿隔离。
4. 中文翻译、英文原文显示、朗读、重播、整句和选中复制、显式选词学习。
5. 学习服务关闭、配置缺失、API 出错时仍能基本输入，设置可以打开修复。
6. 普通 64 位和 32 位编辑应用、资源管理器文件夹命名及常见聊天/浏览器输入。
7. 更新后版本一致、正常卸载、个人词库与配置的保留规则。

这些是后续验收标准，不是已经完成的结果。自动检查不更改默认输入法、
不注册系统组件、不使用个人凭证，也不验证真人听感。
